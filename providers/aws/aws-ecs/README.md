# AWS ECS Provider for EZ4

Provider package providing Amazon Elastic Container Service (ECS) cluster, task definition, and service management for EZ4 applications.

## Overview

- **Cluster**: Manages ECS Fargate clusters.
- **Task Definition**: Handles Fargate task definition creation, hash tracking, and EFS volume mounting.
- **Service**: Generic ECS Fargate service deployment, reconciliation, and deletion.
- **Task**: Client routines for running and inspecting standalone ECS tasks.
